# Platform brand icons

These files are locally hosted official artwork supplied by the platform owners. Keep their aspect ratios and colors intact. The link around each icon provides the accessible platform name.

- `spotify.svg`: Spotify's green RGB primary icon from the official [Spotify design resources](https://developer.spotify.com/documentation/design) package, `2024-spotify-logo-icon.zip`.
- `apple-music.svg`: Apple's small RGB color icon from the official [Apple Music Identity Guidelines](https://marketing.services.apple/apple-music-identity-guidelines) download, `Apple Music_Icon_2020.zip`.
- `bandcamp.png`: current Bandcamp app icon published by Bandcamp Ventures, LLC in its [Apple App Store record](https://itunes.apple.com/lookup?id=706408639&country=us).
- `soundcloud.png`: current SoundCloud app icon published by SoundCloud Global Limited & Co KG in its [Apple App Store record](https://itunes.apple.com/lookup?id=336353151&country=us).
- `youtube.png`: YouTube's official 144px icon served from [Google's YouTube branding CDN](https://www.gstatic.com/youtube/img/branding/favicon/favicon_144x144.png).
- `instagram.webp`: Instagram's current 192px icon served by the [official Instagram site](https://www.instagram.com/).

If a platform updates its mark, replace the matching file from the platform owner's current official resource rather than redrawing or recoloring it.
