# Landing page type

## EPK

`eb-garamond-latin-variable.woff2` is EB Garamond, normal style, variable weights 400–700. The EPK uses it for body text, captions, navigation, and controls, paired only with uppercase Arial Black display text. EB Garamond provides a Garamond serif direction close to the requested Advercase reference. Third-party players control their own internal typography.

Source: [Google Fonts](https://fonts.google.com/specimen/EB+Garamond), Latin WOFF2 from `https://fonts.gstatic.com/s/ebgaramond/v33/SlGUmQSNjdsmc35JDF1K5GR1SDk.woff2`. The file is self-hosted (44 KB); no Google Fonts request is made by the page. License: `EB-Garamond-OFL.txt`, from the [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/ebgaramond).

## Retained artwork font

`instrument-serif-latin-regular.woff2` is Instrument Serif Regular, retained from the earlier between us girls design. The current landing page uses system fonts and does not load this file.

Source: [Google Fonts CSS](https://fonts.googleapis.com/css2?family=Instrument+Serif&display=swap), Latin WOFF2, downloaded from `https://fonts.gstatic.com/s/instrumentserif/v5/jizBRFtNs2ka5fXjeivQ4LroWlx-6zUTjg.woff2`.
