# Landing page type

`instrument-serif-latin-regular.woff2` is Instrument Serif Regular, the lowercase serif used on the between us girls page. It is hosted locally to avoid a runtime font-service request. The sans-serif text uses uppercase Arial Black.

Source: [Google Fonts CSS](https://fonts.googleapis.com/css2?family=Instrument+Serif&display=swap), Latin WOFF2, downloaded from `https://fonts.gstatic.com/s/instrumentserif/v5/jizBRFtNs2ka5fXjeivQ4LroWlx-6zUTjg.woff2`.
